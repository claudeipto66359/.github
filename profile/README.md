<p>判断一条住宅 IP 干不干净，不需要玄学，也不需要供应商的信誉背书，只要把"纯净"拆成四个能查、能问、能留证的字段：归属、类型、滥用历史、共享率。四个字段全部过关，才算可用；有一项含糊，就先别付款。下面这份清单是照着实操顺序排的，从查库到问价到复检，每一步都写了具体动作和判定线，可以边做边打勾。</p>

<h2>一、把"纯净"拆成四个可查字段</h2>
<p>"纯净"是个营销词，落到技术上只对应四件事：这条地址在谁名下、被情报库当成什么类型、过去有没有被人用于批量注册或爬取、现在有多少人同时在用。前两项靠公开查询，第三项靠公开库加时间窗，第四项只能靠问，而且必须问到具体数字。</p>
<h3>字段一：ASN 与注册主体</h3>
<p>用 whois 或 ipinfo 查 ASN，看它挂在住宅宽带运营商、企业专线，还是云厂商与 IDC。挂在云厂商名下的一律按机房地址处理，不管销售怎么说。再看注册国的地址块规模，一个 /24 里塞了几百个"住宅"用户，本身就说明问题。</p>
<h3>字段二：类型标签与代理标记</h3>
<p>主流情报库会给地址打 residential、business、hosting、proxy、vpn 等标签。至少用两个库交叉看，标签一致才可信；两个库打架时按更严格的那个算。标签是长期观测沉淀出来的，供应商改不了，这是它比销售话术可信的原因。</p>

<h2>二、黑名单：三个库、一个时间窗</h2>
<p>黑名单的核心不是"有没有进过"，而是"最近有没有进、因为什么进、出来没有"。一个三年前被投诉过、之后长期干净的地址，比一个上个月刚被移除的地址安全得多。查的时候统一拉 90 天窗口，别只看当前状态。</p>
<h3>三个库的分工</h3>
<p>Spamhaus 看邮件与垃圾信息类投诉，AbuseIPDB 看众包举报的滥用行为，IPQualityScore 这类商业库看综合风险分。三个库结论一致时可信度高；只有一处报警，要看报警的具体类别是不是和你的用途相关。</p>
<h3>时间窗怎么定</h3>
<p>建议固定三个观察点：近 7 天、近 30 天、近 90 天。7 天内干净说明当下没人在拿它做脏活；30 天干净说明不是刚被释放的污染段；90 天干净说明没有周期性滥用。三个点都过，再进入下一项。</p>

<h2>三、历史滥用：看投诉类型，不看投诉总数</h2>
<p>投诉总数是个很粗糙的指标。同样 20 条投诉，全是"垃圾邮件"和全是"撞库尝试"，含义完全不同；前者说明这个段被发信人用过，后者说明它被当成攻击跳板。你要看的是类别分布，以及最后一次投诉距今多久。</p>
<h3>哪几类投诉要直接排除</h3>
<p>批量注册、凭证填充、自动化撞库、支付欺诈这四类，只要在 90 天内出现过一次，就建议直接放弃。这类行为会被平台侧的风险模型长期记住，地址换手也不会清零。相对可以接受的是端口扫描和垃圾邮件，影响面小，观察期拉长即可。</p>

<h2>四、共享率：三个必须问出口的数字</h2>
<p>共享率没有任何公开库能查，只能问。问的时候别用"独享吗"这种封闭问题，销售一定会答"是"；要问能被证伪的数字：同段已售多少条、单条地址允许几个并发会话、同时在线人数峰值是多少。三个数字能对上，才算真独享。</p>
<h3>怎么验证对方说的是真话</h3>
<p>拿到地址后连续挂 48 小时，每十分钟记录一次出口 IP 和响应时间。如果出口 IP 在中途变过，说明你拿到的其实是轮换池；如果响应时间在固定时段规律性飙高，说明这条线被多人共用。数据自己说话，比任何承诺可靠。</p>

<h2>五、五项全过之后，按什么节奏复检</h2>
<p>纯净是个会衰减的状态，不是一次性认证。地址今天干净，不代表三个月后还干净，尤其当它被多人共用过。把复检做成固定动作，比出问题后再排查省事得多，也能提前发现供应商在偷偷超卖。</p>
<h3>周检、月检与季度检各查什么</h3>
<p>每周查一次出口 IP 是否漂移、延迟中位数有没有突变；每月重跑一遍黑名单与类型标签；每季度核对账单、并发实际使用量和替换记录。三档节奏覆盖了绝大多数劣化场景，工作量也不大，脚本化之后基本无人值守。</p>

<h2>常见问答</h2>
<h3>风险分低就代表这条 IP 一定安全吗？</h3>
<p>答：不能这么推。风险分反映的是公开情报库的观测结果，平台内部还有一套不公开的评分，两者不完全重合。风险分低只说明没有明显污点，仍需在实际使用中观察一段时间。</p>
<h3>新买的 IP 需要先"跑"几天吗？</h3>
<p>答：建议先做无登录的连通性测试，再逐步加负载。前两天只做探测和页面访问，第三天开始正常登录，一周后再涉及订阅操作。节奏放缓的意义是让异常尽早暴露在小成本阶段。</p>
<h3>同一个 C 段的其他地址脏，会连累我吗？</h3>
<p>答：有可能。平台侧会把网段作为弱特征参考，同段大量异常行为会抬高整段的关注度。所以除了查单条地址，还要问同段已售情况，必要时要求换到另一个段。</p>
<h3>供应商说可以试用，试用时该测什么？</h3>
<p>答：测四件事：出口是否固定、三个时段的延迟中位数与丢包、黑名单与类型标签、连续 24 小时是否掉线。试用期不测这些，等于把验收推到付款之后，主动权就没了。</p>
